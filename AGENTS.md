## Agent skills

### Issue tracker

Issues live as GitHub issues in `Lumichelka/career-agent`. See `docs/agents/issue-tracker.md`.

### Triage labels

Five canonical triage roles (`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`) plus the wayfinder type labels. See `docs/agents/triage-labels.md`.

### Domain docs

multi-context — per-context `GLOSSARY.md`, indexed by a root `GLOSSARY-MAP.md`. See `docs/agents/domain.md`.
