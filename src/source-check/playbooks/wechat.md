# 微信公众号 · AI 兜底 playbook

**这是兜底，不是自动采集。** 公众号是登录/验证形态的难源：微信验证与登录由用户在可见窗口里
完成，AI 只在文章列表与正文里做抽取；结果走同一套 operator 任务、证据与写入网关，不新建第二套数据。

## 入口

1. 打开 https://mp.weixin.qq.com/
2. 用户登录后，在搜索里找到目标公众号（如「西财校招」「上财就业」）并进入文章列表。
3. 打开一篇文章确认正文结构；文章与活动不是一对一，一篇可能出多条。

## 登录与人工接管

- 微信验证/登录必须由用户接管：任务停在 waiting_login，用户处理后点「已登录，继续」。
- 不提取 cookie/密码，不绕过验证码，不做 stealth。

## 成功判定

- 至少 3 条记录（单位 + 合法 startAt + 文章 URL），证据可追溯，feed 可查。
- 抽不到就返回空并说明原因，0 编造。

## 边界

- 只读文章列表与正文；关注、发消息、支付等动作一律不点（硬确认兜底）。
- 单次 <10 分钟；到时暂停，用户处理后从停点继续。
