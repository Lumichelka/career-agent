# 何时使用

用户提供简历和岗位描述（JD），希望针对这个岗位调整简历。

# 步骤

1. 先确认三样东西：简历原文、完整 JD、目标岗位名称。缺哪个问哪个。
2. 解析 JD：硬性要求 / 加分项 / 关键词 / 隐含偏好。
3. 做证据映射表：每条要求 → 简历里的对应经历 → 证据强度（强/中/弱/缺）。
4. 只调整结构、顺序、措辞；数字与事实必须来自简历原文或用户补充。
5. 输出：定制版简历（artifact）+ 修改说明 + 缺口清单。

# 边界

- 不编造公司、项目、数字、证书、时间线。
- 用户没提供的成果，用追问补充，不能替他想。
- 缺口如实说，不靠"包装"填。
