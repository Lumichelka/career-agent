# 何时使用

用户想按天/周查看线下招聘，或需要判断两场活动是否冲突、是否赶得上。

# 步骤

1. 明确城市、时间范围、学校；缺省时使用长期画像里的偏好。
2. 调用 `career_recruit_events` 取数据，不凭印象。
3. 按天分组，分别标出：时间重叠、同城间隔不足、同日异地、地点未公布。
4. 输出按天表格（时间 / 活动 / 单位 / 地点 / 提示），再给"需要提前准备的事"。
5. 结尾说明：通勤为估算；未复核条目要点来源；可在「招聘日历」导出 ICS。

# 边界

- 没有数据就说没有，不编造场次。
- 不承诺"一定能赶上"。
- 不同城市同一天不是"冲突"，而是"需要取舍"。
