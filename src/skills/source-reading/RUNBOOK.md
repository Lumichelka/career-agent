# 来源阅读 Runbook

> 这是给智能体的工作流，不是采集代码。主站和就业公众号两条通道并行搜索；失败时用视觉模型看截图，不把“抓不到”当成“没有信息”。

## 0. 双通道搜索

对每所学校同时做：

1. **主站**：学校就业信息网/学生就业指导中心。
2. **就业公众号**：搜索“学校名 + 就业/校招/就业指导中心”；核验公众号名称、biz、最近文章。
3. **替代**：省级高校毕业生平台、24365、国聘、学校新闻网/学院通知。

搜索词模板：

```text
<学校> 2027届 校园招聘 就业
<学校> 就业 公众号
<学校> 双选会 参会单位
site:mp.weixin.qq.com <学校> 招聘
```

## 1. 页面打开

- 先用 BrowserSkill/Agent Window 打开真实页面。
- 记录标题、是否有登录墙、验证码、全屏遮挡。
- 不要用 HTTP 200 代替页面内容。

## 2. 需要人工时

- 登录/扫码/验证码：停下来，说明操作，等待用户完成；用户可取消该环节。
- 用户完成后再截图/读取，不替用户输入凭据。
- 用户发截图时，先确认截图对应页面，再读；无法辨认的字段留空。

## 3. 视觉模型截图流程

1. `bsk_inspect screenshot` 截当前页。
2. 看截图确认：活动名、日期、地点、参会单位、是否登录/遮挡。
3. 截图中无法确认的内容，标“未确认”，不猜测。
4. 需要更细的单位表时，向下滚动/翻页后再截一张。
5. 用户提供的截图与浏览器截图分开记录来源。

## 4. 每站检查表

- [ ] 主站打开过
- [ ] 就业公众号搜索过
- [ ] 最近文章/活动日期可确认
- [ ] 参会单位是否在正文/详情/附件中
- [ ] 登录/验证/robots 限制已记录
- [ ] 替代渠道已搜索
- [ ] 未确认字段没有编造

## 5. 2026-10-25 实测记录

### 中央财经大学

- 主站 `scc.cufe.edu.cn`：`ERR_CONNECTION_TIMED_OUT`。
- Bing 搜索“中央财经大学 2027届 校园招聘 就业”：可见信息学院 2027 届招聘邀请函、学生工作部就业创业指导中心。
- 视觉读取：搜索结果标题“才遇信息，职引未来——中央财经大学信息学院2027届毕业生秋季校园招聘邀请函”。
- 结论：主站被网络阻断；通过学院站/Bing 可读到邀请函。需要具体活动/单位时让用户发页面截图。

### 对外经济贸易大学

- 首页是全屏轮播 banner，首屏看起来像“国聘行动/邀请函”遮挡。
- 点击顶部“就业 Employment”后进入就业页；可读通知公告、就业新闻，但没有稳定的活动结构表。
- 视觉读取：可见“对外经济贸易大学2027届毕业生秋季校园招聘邀请函”等通知。
- 结论：不自动解析；用用户截图或公众号文章补活动。

### 西南财经大学

- `job3.swufe.edu.cn` 的 robots 禁止自动抓取。
- BrowserSkill 截图可见：2026 年秋季大型双选会，2026-10-27 14:00，柳林校区柳林体育馆；“已停止预订”“参会企业”。
- 公众号“西财就业”已迁移/合并为“西财校招”，biz `MjM5MDAxMzM4MQ==`。
- 结论：只用用户截图/公众号文章，不自动抓。

### 四川大学公众号

- 真实文章“线下双选 | 5月8日 | ‘周五职通车’——2027届实习专场”。
- 微信首次打开出现“环境异常”，用户完成验证后正文可读。
- 视觉/正文读取：26 家参会单位，含德州仪器、攀钢集团等。
- 结论：公众号文章分析器可抽出 26 家；验证是抓取瓶颈。

### 其他已确认源

- 川大宣讲/双选、川农 JSON、西南石油、上财 POST、电子科大日历：主站结构正常。
