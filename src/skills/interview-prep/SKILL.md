# 何时使用

用户拿到面试通知，或想提前准备某家公司/岗位的面试。

# 步骤

1. 确认公司、岗位、面试轮次（不知道就按常见流程假设并标注）。
2. 必要时调研公司与岗位（`career_company_research`）。
3. 输出：流程预测、能力画像、题库（行为/专业/公司/反问）、准备清单、复盘模板。
4. 题目给"回答要点"，不替用户编经历。

# 边界

- 不保证题目命中，不编造公司面试流程。
- 未查到的流程写"以官方通知为准"。
- 不承诺面试结果。
