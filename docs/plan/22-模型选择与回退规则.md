## 0. 范围与不变量

**覆盖**：网页端一次任务用哪个后端（模型 API / 本机 Codex / 本地模型 / 外部 Agent）、默认值、能力不符时怎么选、失败后按什么顺序建议、何时要用户点一次、调用怎么记账与展示。

**不覆盖**：多用户 Key 与浏览器登录隔离（#14）；审计表与撤销实现（#15）；MRTR 与出站连接（#13）；面板视觉（#18/#24）；图片的存储与脱敏（地图 fog）。

**不变量**：

1. **无静默替换**：系统不替用户换后端。任何换后端都是一次点击；消息里说的"自动"只指"自动排出候选与顺序"。
2. **能力定候选**：候选只从满足本轮能力（text / vision / tools）的后端里出；不满足就停下列候选，不降级、不猜。
3. **副作用门**：本轮一旦有工具调用成功，失败即停，不再提供换后端建议（避免重复读与重复写；写另有 #15 幂等兜底，但不因此放开自动）。
4. **视觉只走模型 API**：外部 Agent 读图没有一手依据（研究 §6），不作为视觉候选，也不写进任何默认。
5. **成本不设限**（Q10）：不设软/硬/每日预算，不因费用暂停或降级；金额只记录与展示。Q6 原先的预算执行与 Q7 第 ④ 类拦截随之取消。跑飞的兜底靠结构性上限（§6.2）。
6. **记录是元数据**：调用记录只存后端、耗时、tokens、估算费用、结果；不存提示词、不存结果正文，且只有本人可见（Q8）。
7. 后端配置与凭据按 `user_id` 隔离；存储细节归 #14，本决议只约束行为。

## 1. 术语

| 术语 | 含义 |
| --- | --- |
| 后端 | 一次可执行任务的目标：`codex`（本机 Codex）/ `local`（Ollama、LM Studio）/ `api`（模型 API）/ `agent`（外部 MCP Agent）。 |
| 能力 | `text`、`vision`（能读图）、`tools`（本应用工具）、`agent_tools`（外部 Agent 自有工具）。 |
| 当前选择 | 该用户"上次用的后端"；本轮开始时读取，下一轮生效。 |
| 候选 | 满足本轮能力、且该用户已配置并启用的后端集合。 |
| 换后端 | 从当前选择切到另一个后端实例；一次点击才发生。 |
| 回退建议 | 失败后按价格升序算出的"下一个候选"，只建议不执行。 |
| 调用记录 | 每次模型/Agent 调用的元数据行（§5）。 |

## 2. 选择（Q1/Q2/Q4）

### 2.1 手动为主

- 顶栏常驻：`当前：<后端名>｜本轮 ≈¥x｜🔒 本次锁定`。
- 切换后立即保存为该用户"上次选择"，**下一轮生效**；本轮进行中不可换（要换先停）。
- 模型 API 与外部 Agent 分开选：顶栏两个入口，互不覆盖。

### 2.2 默认

| 场景 | 默认 |
| --- | --- |
| owner 首次 | 本机 Codex（已登录即用）；Codex 不可用则无默认、引导配置。 |
| 非 owner 首次 | 无默认、引导配置；推荐位两个：**DeepSeek**（`deepseek-flash`，视觉＋工具，USD 计费）与**智谱免费档**（`glm-4.6v-flash` 视觉、`glm-4-flash-250414` 文本，¥0）；不强制、不代填 Key。 |
| 已配置用户 | 沿用上次选择；配置删除/损坏 → 回到"无默认"。 |
| 外部 Agent | 无默认；未配置时不出现在候选列表；首次调用仍走 §4 的出网确认。 |

### 2.3 能力解析

每轮开始时从输入推导能力：附件含图片 → `vision`；技能声明的 `tools` 只约束本应用工具，不参与后端选择；其余默认 `text + tools`。

- 当前选择满足 → 直接开始，**不弹任何东西**。
- 不满足 → 停下，顶栏列候选卡：`名称 · 能力 · 约 ¥x/次（有价才显示） · 配置…`。点击一张 = 设为当前选择并开始本轮。
- 没有候选（一个视觉后端都没配）→ 引导去设置页，不自动装、不自动选。
- 外部 Agent 永远不因 `vision` 入选；用户带着图片选了 Agent → 提示"外部 Agent 不读图，换视觉模型或去掉图片"。

### 2.4 锁定

- 「本次锁定」只锁本轮：任何回退建议都不越过它；下一轮默认解除。
- 锁定时若失败：只报错与"重试"（同后端），不给换后端。

## 3. 回退（Q3/Q4）

### 3.1 何时给建议

一次模型调用失败（连接 / 超时 / 鉴权 / 额度 / 5xx / 协议不符），且**本轮尚无工具调用成功**。

### 3.2 顺序

1. 同能力（视觉任务仍只出视觉后端）、该用户已配置且启用；
2. 按**预估单次费用升序**；本机模型（¥0）自然最前，未知价的后端排在有价之后；
3. 同价按设置页顺序；
4. 一次失败只建议**一个**下一个候选；连续失败最多建议 3 个，之后只显示错误与手动选项，防连锁换到贵模型。

### 3.3 动作

- **不自动执行**：弹出「换 <Y> 重试（约 ¥x）」，点一次才换；点击后记一条回退记录，并用 Y **重跑整个本轮**（不续跑半截、不复用旧输出）。
- 顶栏同时提示"已回退到 Y"；调用记录里该行标 `fallback`。

### 3.4 副作用门

- 本轮已有工具调用成功 → 失败即停：只显示错误、「重试」（同后端）、「停止」。
- 不提供换后端建议，不自动重跑。

### 3.5 外部 Agent

- 只走 #13 的连接退避与重连；工具失败不换 Agent、不降级到模型 API、不跨 Agent。
- Agent 未配置/不可用 → 直接报错，不触发模型 API 回退。

### 3.6 保留与明确不做

- 保留：同一后端的传输级重试（429 / 5xx / 超时，≤3 次，现有行为），不算换后端、不要点击。
- 不做：任何静默换后端；跨 `codex`/`agent` 的自动回退；已产生副作用后的自动重跑；对已发出请求的重发。

## 4. 确认（Q7）

只三类拦截（Q10 不设限后，原第 ④ 类"硬预算"取消）：

1. **敏感写**：#15 的 `confirm_id`，本应用 UI 内确认（已定）。
2. **换后端**：本轮要换成没选过的后端时（能力解析点击、回退建议点击）——一次点击，同一后端不重复问。
3. **首次出网**：内容第一次交给某个外部 Agent 时确认一次，按 `(user, agent)` 记；文案「<Agent> 会看到你交给它的内容；上游副作用不可撤销」，给「仅本次 / 以后不再问」。#13 的"首用提示"并入这一次，不重复弹。

不拦：普通读、同后端重试、用户主动的顶栏切换、金额（不设限）。

## 5. 调用记录（Q8 = B）

### 5.1 数据形状（只存元数据）

```text
CallRecord {
  step          'plan' | 'act' | 'review' | 'sample'   // sample = MRTR 补全
  backend       { kind, preset?, model, agentId?, label }
  at, durationMs, outcome    'ok' | 'failed' | 'fallback'
  usage?        { input, output, total, image?, cached? }   // 供应商回传才写
  cost?         { cny, estimated: true, priceVersion, sourceUrl }
  errorCode?    'CONNECT_FAILED' | 'AUTH_FAILED' | 'REQUEST_TIMEOUT' | ...
}
```

### 5.2 展示

- **只放在助手消息下**：折叠「本次调用（N 次 · ≈¥x · 12,345 tok）」，表头 步骤 / 后端 / 耗时 / 输入·输出 / ≈¥ / 备注（回退、失败码）。
- **不进工作台任务记录**（用户选 B）；`recordTask` 维持现有 `steps/tools/durationMs`。
- 存储：会话 JSON 的 `messages[].calls`；只有本人可见；随会话删除；不复制进任何审计或证据文件。

### 5.3 降级

- Codex：事件里没有 usage 就显示「订阅额度」，有就照记。
- 供应商没回 usage：显示「未回传」，**不估算**。
- 价表里没有该模型：只显示 tokens，不显示金额。

## 6. 成本与延迟（Q6/Q10）

### 6.1 不设限

不设软上限、硬上限、每日上限；不因费用暂停、不因费用降级、不弹预算确认。金额只用于展示与事后看账。

### 6.2 结构性上限（兜底，保留或调整）

| 项 | 值 | 现状 |
| --- | --- | --- |
| 整任务总时长 | **15 分钟**（`runAgent` 与 Codex 统一） | Codex 8 分钟、`runAgent` 10 分钟，统一为 15 |
| 模型调用轮次 | ≤9 轮/任务 | 现有 |
| 工具调用 | ≤8 次/任务 | 现有 |
| 单条工具结果给模型 | 64KB 截断 | #13 |
| 单次模型请求 | 沿用现有 240s 默认（可按后端覆盖）；本决议不新增上限，首 token 提示不做要求 | 现 240s 默认 |
| 排队、连接、上游超时 | 归 #13 | #13 |

### 6.3 用量采集

| 协议 | 取法 |
| --- | --- |
| chat 流式 | 必传 `stream_options.include_usage`；最后 chunk 的 `usage`；Kimi 还会发一个 `choices` 为空的独立统计块，必须接受；不假设每个 chunk 都有 `choices[0]`。 |
| chat 非流式 | `data.usage`。 |
| messages（Anthropic） | `usage.input_tokens` / `output_tokens`。 |
| responses | `usage.input_tokens` / `output_tokens`。 |
| 思考 token | 计入输出，按供应商回传值，不二次拆分。 |
| 阿里 `image_tokens` | 只在 DashScope 原生响应；OpenAI 兼容路径只取 `prompt/completion/total`。 |

### 6.4 计价

- 内置价表（实现命名如 `src/model/prices.mjs`），**随版本发布、不联网**；每条带 `sourceUrl` 与访问日期。
- 币种：统一折人民币展示，USD→CNY 固定 **7.2**（常量，可配），金额一律标「≈¥ / 估算」。
- 缺价：只显示 tokens，不显示金额；估算永不冒充实付。
- 缓存价与阶梯价：按供应商回传的 usage 与本次请求输入量套牌价；不预测、不折算。
- 候选卡的「约 ¥x/次」按研究 §4 公式估算，标「约」，与实际记账分开。

### 6.5 不做

不拉实时价、不换算实时汇率、不做月度账单、不设每人配额。

## 7. 型号迁移（事实，随实现）

研究 §0/§2 已确认仓里预设的默认型号多数过期。实现第一步按下表更新预设，**不静默改用户已保存的模型名**：

| 预设 | 仓里现值 | 现行可用 | 视觉 |
| --- | --- | --- | --- |
| deepseek | `deepseek-chat` | `deepseek-flash`（默认）/ `deepseek-v4-pro` | flash 是，每图 ≤1024 token |
| zhipu | `glm-4-flash` | `glm-5.3-flash`（默认）/ `glm-4-flash-250414`（免费文本） | `glm-4.6v-flash` 免费 / `glm-4.6v` |
| moonshot | `moonshot-v1-8k` | `kimi-k3.1-pro` | 是，仅 base64 / `ms://`，不支持公网 URL |
| qwen | `qwen-plus` | `qwen3.7-plus`（文本）/ `qwen3.8-max`（视觉） | 是；接入点含 WorkspaceId，价表后段未取得 |
| siliconflow | `Qwen/Qwen2.5-7B-Instruct` | 按价表 | 是（`zai-org/GLM-4.5V` 等） |
| volc | 空（`ep-` 手填） | 未取得 | 未取得 |
| openai / anthropic / gemini | 旧型号 | 未取得 | 未取得 → 只记 tokens |
| ollama | `qwen2.5:7b` | `qwen3-vl:8b` 等本机已装 | 是，仅 base64 |
| lmstudio | `local-model` | 本机已加载模型 | 是 |
| WorkBuddy | 无 | 无官方 baseUrl/型号 | 未取得 → 先按「自定义接口」用，不进预设 |

规则：

- 用户已保存的模型名不自动改；设置页检测到型号不在现行列表时提示「该型号可能已下线」＋「切换到 <新默认>」一键按钮（点了才改）。
- 价表按"预设 + 模型名"匹配；匹配不到 = 无价。
- 供应商新增/改名随版本更新价表；不做联网探测。

## 9. 明确不做

- 自动路由（按阶段换模型、静默降级）、预算熔断、配额、月度账单。
- 外部 Agent 读图/视觉、Agent 与模型 API 互相兜底。
- 任务记录里的调用明细（用户选 B）。
- 图片附件的存储、脱敏、重试（地图 fog，另票）。
- 用户自定义价表、实时汇率、联网拉价。

## 10. 验收（可直接当回归脚本）

1. **截图选路**：owner 当前 Codex（无视觉）→ 发一张双选会截图 → 顶栏出现候选（DeepSeek flash / 智谱免费视觉）→ 点一个 → 成功 → 助手消息下出现调用表（tokens + ≈¥），工作台任务记录**没有**新增明细。
2. **回退一次点击**：断网 → 本轮无工具成功 → 出现「换 <备用> 重试（约 ¥x）」→ 点一次 → 成功 → 记录标 `fallback`；若本轮已有工具成功，则只出现重试/停止。
3. **出网确认**：首次让外部 Agent 执行 → 弹一次确认 → 选「以后不再问」→ 同一 `(user, agent)` 不再弹；换 Agent 再弹。
4. **副作用门**：先成功调用一次只读工具，再让模型失败 → 不出现换后端建议。
5. **不设限**：构造多轮长任务，金额涨到几元也不停；只有 15 分钟到点才停。
6. **型号过期**：把模型名改成 `deepseek-chat` → 设置页提示，一键切 `deepseek-flash`。
7. **用量口径**：mock Kimi 的独立 usage 块（`choices` 为空）→ 记录仍算入 tokens；mock 无 usage 的响应 → 记「未回传」。

## 11. 实现检查清单

- [ ] 顶栏：当前后端、本轮 ≈¥、本次锁定；切换下一轮生效。
- [ ] 能力解析候选卡（视觉只从模型 API 出；Agent 排除）。
- [ ] 回退建议：同能力、价格升序、一次点击、副作用门、≤3 个。
- [ ] 三类确认：敏感写 / 换后端 / 首次出网（含"以后不再问"）。
- [ ] 调用记录：助手消息折叠表；元数据；Codex、缺 usage、缺价的三种降级。
- [ ] usage 三协议 + Kimi 独立块 + 阿里 `image_tokens` 不误用。
- [ ] 价表 + 7.2 汇率 + `≈¥` 标注 + 未知价降级。
- [ ] 统一 15 分钟；单次超时沿用现有默认、不新增要求。
- [ ] 预设型号迁移与旧型号提示（不静默改用户配置）。
- [ ] 契约测试：失败面、回退、确认、记录、降级。
