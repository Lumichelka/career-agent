# 14 · 多端、部署与备份（M12）

> 目标：手机/平板/另一台电脑能安全访问；数据能备份、能搬走；出问题能回退。

---

## 1. 三种访问方式

| 方式 | 适合 | 安全边界 |
| --- | --- | --- |
| 同一 Wi-Fi | 手机在家/宿舍用 | 局域网内可见，靠账号 + 访问口令 |
| Tailscale | 不在同一网络（如图书馆/公司） | 私有虚拟网络，不暴露公网 |
| Docker / 云服务器 | 长期在线、多人用 | 必须加 HTTPS 反代，不建议直接暴露 4189 |

### 1.1 同一 Wi-Fi（已实测）

1. 双击 `开始使用-局域网.cmd`（或 `node scripts/launch.mjs --lan`）；
2. 控制台会打印 `http://192.168.x.x:4189`；
3. 手机浏览器打开，用账号登录；
4. 如果手机打不开：检查 Windows 防火墙是否放行 Node，或换 Tailscale。

### 1.2 Tailscale（推荐跨网络）

1. 电脑和手机都安装 Tailscale，登录同一账号；
2. 电脑启动：`set CAREER_HOST=0.0.0.0` 后运行 `node scripts/launch.mjs`（PowerShell 用 `$env:CAREER_HOST="0.0.0.0"`）；
3. 手机访问 `http://<电脑的 Tailscale IP>:4189`；
4. 如需 HTTPS：`tailscale serve https / http://127.0.0.1:4189`，用返回的域名访问，并把域名加入 `CAREER_ALLOWED_HOSTS`。

### 1.3 Docker

```bash
docker compose up -d --build
# 打开 http://127.0.0.1:4189
# 首次登录密码在 ./data-docker/首次登录.txt
```

- 数据挂载在 `./data-docker`；
- 升级：`docker compose build && docker compose up -d`；
- 停止：`docker compose down`（数据保留在卷目录）。

> 本机没有安装 Docker，**镜像构建未实测**；Dockerfile / compose 已按 Node 24 + 数据卷写好，构建失败时先看 `docker compose logs`。

## 2. 环境变量

| 变量 | 默认 | 作用 |
| --- | --- | --- |
| `PORT` | `4189` | 端口 |
| `CAREER_HOST` | `127.0.0.1` | 监听地址；`0.0.0.0` 开放局域网 |
| `CAREER_ALLOWED_HOSTS` | 空 | 额外允许的 Host（域名/Tailscale 域名，逗号分隔） |
| `CAREER_DATA_DIR` | `%LOCALAPPDATA%\ZhiXiang` | 数据目录；Docker 里设为 `/data` |
| `CAREER_MODEL_API_KEY` | 空 | 可选：从环境变量读模型 Key（不落盘） |
| `CAREER_BACKUP_DIR` | `./backups` | 备份输出目录 |
| `CAREER_BACKUP_KEEP` | `5` | 保留最近几份备份 |

## 3. 备份

```bash
node scripts/backup.mjs
# 或 npm run backup
```

输出：

```
已备份 1062 个文件（104.4 MB）到 F:\职向\backups\zhixiang-20261024-170606-8282
清单：...\backup-manifest.json
```

- 备份内容：账号、招聘库、简历/投递/面试、模型设置、平台登录态、日志；
- 每份备份有 `backup-manifest.json`（版本、时间、文件数、字节数）；
- 默认保留最近 5 份，旧的自动删除；
- **备份目录不能放在数据目录里面**（脚本会拒绝，避免递归）。

### 恢复

1. 停止服务；
2. 把备份目录里的文件复制回数据目录（覆盖）；
3. 启动服务，用原账号登录。

> 恢复前建议先把当前数据目录改名留底，确认新数据正常后再删。

## 4. 安全清单

- 默认只监听 `127.0.0.1`，不开公网；
- 开放局域网时必须保留账号密码，不要把 `local-session-token` 发给别人；
- 公网访问必须加 HTTPS 反代（Caddy/Nginx），不要直接暴露 4189；
- `secrets.enc.json`、`vault.key`、平台登录态、简历都在数据目录，**不进 Git**；
- 换电脑：复制数据目录即可，模型 Key 用同一把 `vault.key` 才能解开；
- 不要用别人的电脑保存平台登录态。

## 6. 常见问题

| 现象 | 处理 |
| --- | --- |
| 手机打不开 | 确认同一 Wi-Fi、`CAREER_HOST=0.0.0.0`、防火墙放行 Node |
| 403 Host rejected | 把访问用的域名/IP 加到 `CAREER_ALLOWED_HOSTS` |
| 端口被占用 | `PORT=4190 node src/server/index.mjs` |
| 忘记密码 | 看数据目录 `首次登录.txt`；仍不行则备份后重建账号 |
| 模型调用失败 | 对话页「模型与接口设置」→ 一键体检 |
| 备份失败 | 检查目标磁盘空间；不要把备份目录设在数据目录内 |
