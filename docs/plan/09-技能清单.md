# 09 · 技能清单（M7 已落地）

> 工具是"能做什么"，记忆是"记得什么"，**技能是"按什么流程做"**。
> 每个技能是一个目录：`src/skills/<id>/SKILL.md + prompt.md + checklist.md`。

![能力面板](../assets/capabilities.png)

---

## 1. 四个技能

| 技能 | 触发词（示例） | 可用工具 | 产出 | 对应作业 |
| --- | --- | --- | --- | --- |
| `schedule-planner` 行程规划 | 排行程 / 这周有什么 / 宣讲会 / 双选会 / 冲突 | `career_recruit_events` | 按天行程表 + 冲突/异地取舍 + 准备事项 | 2.1、2.3 |
| `company-research` 公司调研 | 公司怎么样 / 这家公司 / 口碑 / 待遇怎么样 | `career_company_research`、`career_public_search` | 行业/规模/校招/待遇/评价 + 来源 | 2.2 |
| `resume-tailoring` 简历定向 | 改简历 / 优化简历 / 简历 / 岗位要求 / JD | 无（用附件与画像） | 证据映射表 + 定制版简历 + 缺口清单 | 3.1 |
| `interview-prep` 面试准备 | 面试 / 面经 / 面试题 / 模拟面试 / 无领导 | `career_company_research`、`career_public_search` | 流程预测 + 题库 + 准备清单 + 复盘模板 | 3.1 |

全部 `writes: false`（只读），不会改数据。

## 2. 技能怎么被选中

```
用户消息
   │
   ▼
遍历所有 SKILL.md 的 triggers
   │
   ├─ 命中多个 → 取最长触发词（"改简历" 优先于 "简历"）
   ├─ 命中一个 → 直接启用
   └─ 没命中  → 不启用技能，走通用流程
```

- 选择是**确定性**的，不靠模型猜；
- 选中后聊天状态会显示「使用技能：行程规划」；
- 助手消息和任务记录都会记下 `skill`，方便回看。

---

## 3. 技能如何限制工具

技能声明 `tools: [...]` 后，模型在本次任务里**只能看到这些工具**：

| 技能 | 模型看到的工具 |
| --- | --- |
| 行程规划 | 只有 `career_recruit_events` |
| 公司调研 | 两个搜索类工具 |
| 简历定向 | 没有工具（避免跑题去搜岗位） |
| 面试准备 | 两个搜索类工具 |

这是"技能 = 权限边界"的体现：不会出现"让它改简历，它却去开浏览器"。

---

## 4. 每个技能里写了什么

| 文件 | 作用 |
| --- | --- |
| `SKILL.md` | 何时使用、步骤、边界（人读；顶部 `---` 是元信息） |
| `prompt.md` | 给模型的硬约束：输出结构、禁止项 |
| `checklist.md` | 验收清单，复核阶段对照 |

例如 `resume-tailoring` 的提示词明确要求：

- 先做 **证据映射表**（JD 要求 → 你的经历 → 强/中/弱/缺）；
- 只调整结构、顺序、措辞；
- 数字、公司、时间线必须来自原文；
- 缺口如实列出，不"包装"。

## 5. 怎么新增一个技能

```
src/skills/<id>/
├─ SKILL.md      # 元信息 + 步骤 + 边界
├─ prompt.md     # 模型约束
└─ checklist.md  # 验收
```

1. 复制一个现有目录改名；
2. 改 `id/name/triggers/tools`；
3. 写步骤与禁止项；
4. 重启服务，能力面板自动出现；
5. 加一条路由测试（`tests/skills.test.mjs`）。

**不需要改模型层、前端或服务端。**

---

## 6. 验证

- 6 项技能测试：清单、加载、路由、提示词、工具限定、完整链路；
- 实测：说"这周成都有什么宣讲会？帮我排一下" → 状态显示「使用技能：行程规划」→ 任务记录里 `skill=行程规划`；
- 能力面板显示 4 个技能、每个技能的触发词与可用工具。

## 7. 已知边界

- **简历定向**目前处理用户粘贴/上传的简历文本，还没有"简历版本库"（M11）；
- **面试准备**是文本题库，没有语音模拟（可作为后续扩展）；
- **公司调研**依赖 SearXNG 搜索地址，未配置时会如实返回"不可用"；
- 技能不会自动写数据；保存简历版本/投递记录要等写工具 + 确认流程（M11）。
