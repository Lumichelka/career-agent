## 2. 请求与数据流

```
浏览器
  │  GET / /chat /recruit /resume /companies
  ▼
src/server/app.mjs ──静态页 + token 注入
  │  /api/*
  ├─ 招聘   → src/recruit/api.mjs   → store / collect / schedule / manual
  ├─ 简历   → src/resume/api.mjs    → resume.store / docx
  ├─ 公司   → src/company/api.mjs   → company.store + recruit/resume 关联
  └─ 对话   → src/agent/agent.mjs   → src/model/api-model.mjs
                                      │  工具调用
                                      ▼
                              src/tools/execute.mjs
                                      │  handlers/*
                                      ▼
                          recruit / resume / company / search / platform
```

关键边界：

- **模型层只负责协议**（OpenAI / Anthropic、流式、重试、代理），不写业务；
- **工具定义只有一份**：`tools/registry.mjs`；参数校验 `policy.mjs`；执行 `execute.mjs`；
- **技能只做提示词与工具白名单**：`skills/index.mjs` 负责按触发词选择；
- **每个业务有自己的 store**，互不直接读写对方的表。

## 5. v2 → v3 对照

| v2 | v3 | 变化 |
| --- | --- | --- |
| 根目录 24 个平铺文件 | `src/{server,agent,model,tools,skills,recruit,resume,company,web}` | 按职责分层 |
| `server.mjs` 368 行 | `src/server/app.mjs` | 仍是总装点，但业务已下沉 |
| `recruit/sources.mjs` 313 行 | `src/recruit/sources/*.mjs`（13 个） | 一校一文件，自动发现 |
| `API_TOOLS` / `tool-policy` / `platform-mcp` 三处 | `tools/registry.mjs` 一处 | 定义、校验、MCP 同源 |
| 工具实现写在 `api-model.mjs` | `tools/handlers/*` | 模型层只做协议 |
| 只有会话记忆 | `agent/memory.mjs` 三层 | 会话/画像/任务 |
| 前端补丁覆盖 | 独立页面 + `artifact.js` | 路由清晰 |
| 运行时 `.data` 在项目内 | `%LOCALAPPDATA%\ZhiXiang` | 不进 Git |
| `sources` 无生命周期 | active/cancelled/possibly_removed | 三振、截断保护、多源 |
| 无版本控制 | `main` / `dev` + 标签 | 可逐模块回退 |

## 6. 数据目录（项目外）

```
%LOCALAPPDATA%\ZhiXiang\
├─ accounts.json          账号（scrypt）
├─ 首次登录.txt            初始密码
├─ local-session-token    本机访问口令
├─ users/<id>/.data/
│  ├─ recruit.db          活动、源、运行、原文
│  ├─ resume.db           简历、版本、投递、面试准备
│  ├─ company.db          公司档案
│  ├─ wechat.db           公众号账号/文章
│  ├─ memory/             画像、任务
│  ├─ <sessionId>.json    对话
│  ├─ model-settings.json 模型配置
│  ├─ secrets.enc.json + vault.key
│  ├─ platform-profiles/  BOSS/小红书登录态（最大）
│  └─ server.log
└─ logs/
```

- 默认 `git` 忽略；备份用 `node scripts/backup.mjs`；
- 复制数据目录即可搬家；`vault.key` 必须一起复制，否则 Key 解不开；
- Docker 挂载 `/data`。
