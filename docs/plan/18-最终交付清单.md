## 1. 30 秒开始

1. 安装 **Node.js 23+**；
2. 双击 `开始使用.cmd`；
3. 浏览器打开 `http://127.0.0.1:4189/`；
4. 首次用 `%LOCALAPPDATA%\ZhiXiang\首次登录.txt` 的账号登录；
5. 左侧「模型与接口设置」→ 选预设、填 Key → 一键体检 → 保存；
6. 回到 `/recruit` 点「采集全部已接入源」。

数据在 `%LOCALAPPDATA%\ZhiXiang`，不在项目里；换电脑复制该目录即可。

## 8. 已知限制（如实写）

1. 电子科大、成都理工、央财未接入；西南财大因 `robots.txt` 禁用。原因都在源卡片上，不伪装成“没有活动”。
2. 公众号是半自动：用户给链接/正文，解析后确认入库；不批量监控。
3. 通勤是估算，不是实时路况；地图链接用于出发前复核。
4. 没有语音模拟面试；题库、回答、复盘字段已就绪。
5. Docker 镜像未在本机实测（无 Docker 引擎）。
6. 公司/活动关联按名称包含匹配，简称可能匹配不上。
7. Word 导出是基础样式，复杂表格/分栏需在 Word 里再调。
