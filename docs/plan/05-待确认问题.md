## Q2 数据目录：`.data` 要不要搬出项目？

| 选项 | 说明 |
| --- | --- |
| **A. 外置到 `%LOCALAPPDATA%\ZhiXiang`（建议）** | 项目只剩 ~1 MB；分享/提交 git 不会带隐私；浏览器缓存不再拖慢文件夹 |
| B. 项目内 `data/`（git 忽略） | 便携（整个文件夹拷走即可），但仍有 100 MB+ |

> 现状：`.data` 104 MB，其中 103.7 MB 是 Edge 浏览器缓存。搬走后文件夹会立刻"变轻"。
> 迁移方式：复制不删除，首次启动检测旧目录并提示。
