## 0. 范围与不变量

**覆盖**：首个端到端场景——西南财大双选会页面 → 应用内浏览器截图 → 视觉模型 API 抽取活动与单位 → 外部 Agent 文本复核 → 本应用写 `events` / `event_projects` → 审计 → 任务级撤销。

**不覆盖**：实现代码、真实用户数据、手机端逐屏、入站 `/mcp` 写、公司档案、全局审计入口、跨重启恢复。

1. **采集器不进首验**：`swufe.mjs` 保持 `enabled:false`，不跑 `runCollection`；`source_id` 用 `manual`，不用采集器。
2. **不直接 HTTP 抓取**：应用不调用 `fetchText` / 采集器请求 `*.swufe.edu.cn`；只允许应用内普通浏览器单页读取（列表 1 次 + 详情 1 次）。
3. **视觉只走模型 API**：`deepseek-flash` 或 `glm-4.6v-flash`；外部 Agent 只做文本复核，不读图、不写库。
4. **写入最小面**：只写 `recruit.events` + `recruit.event_projects`；审计、幂等、数据同库同事务，fail closed。
5. **复核建议制**：不自动改写入集；Agent 不可用不阻塞写库，但 Agent 路径不算通过。
6. **撤销是新的正向写入**：任务级撤销逐批事务；冲突可强制；不做 redo。
7. **第三方个人信息不落库**：联系人 / 手机 / 邮箱 / 微信 / 身份证等字段丢弃，不入库、不进审计。

## 1. 术语

| 术语 | 含义 |
| --- | --- |
| 来源校对 | 从数据页来源卡片发起的读取任务；本场景读取西南财大双选会页面。 |
| 浏览器读取 | 应用内 Playwright/Edge 单页打开 + 截图 + 可见文本；不是采集器，不是 HTTP fetcher。 |
| 抽取 | 视觉模型 API 把截图转为结构化 JSON（活动 + 单位 + 证据位置）。 |
| 复核 | 外部 Agent 只读抽取 JSON，返回问题列表；不改数据、不读图。 |
| 批次 | 一次写工具调用；任务可含多个批次；撤销按批次。 |
| 可读 | 截图中人眼可辨认；模糊、截断、被遮挡的不算分母。 |

## 2. 环境与数据隔离

- Windows 本机，Node ≥ 23，Edge（Playwright）。
- 独立 `CAREER_DATA_DIR`（空临时目录）；新建 owner 验收账号；空 `recruit.db`；不碰真实用户数据。
- 至少一个视觉 Key：`deepseek-flash` 或 `glm-4.6v-flash`；文本后端 owner 的 Codex 或 DeepSeek；一个外部 Agent（Claude Code；不可用回退 Coze）已配置并启用。
- 验收前 / 后快照：停写后复制 `recruit.db`（含 WAL checkpoint）或 SQLite backup；记录 `events` / `event_projects` 行数 + 内容 sha256；`write_audit` / `idempotency` 单独核对，不参与「数据一致」比较。

## 3. 入口与流程

1. 数据页 → 来源 → 西南财大卡片（`disabled`，原因 robots）→「来源校对」。
2. 提示「采集器禁用，改用浏览器读取」；用户确认开始。
3. 应用浏览器工具打开列表页，截图 1；进入 1 场活动详情，截图 2；允许页内滚动，不翻页、不批量。
4. 任务回到对话页并打开 [工作流面板与任务状态原型](https://github.com/Lumichelka/career-agent/issues/18) 的抽屉；任务卡显示「运行中」。
5. 视觉模型 API 抽取 → 外部 Agent 复核 → 本应用写库 → 审计 → 任务卡「成功」；单位挂到对应活动。
6. 打开审计面板，跑任务级撤销。
7. 遇登录 / 验证码 / 阻断：停止，任务卡显示 blocked + 原因 + 建议（人工截图或公众号），不绕过；用户可取消。
8. 源卡片**不**变成「已接入」；只记「最近手动读取 + 原因」，不写采集器的 `last_run` / `last_status` 语义。

## 4. 浏览器边界

- Playwright/Edge，headless 或 headed 均可；**不得启用 stealth / 反检测参数**（例如 `--disable-blink-features=AutomationControlled`）、不得伪装 UA / 指纹。
- 只访问 1 个列表 + 1 个详情；页内滚动允许；不翻页、不并发、不批量。
- 截图存 `users/<id>/tasks/<taskId>/evidence/`（#13 §8.2）；记录 URL、页面标题、时间、视口尺寸。
- 站点 `robots.txt` 为 `Disallow: /` 已知；本验收接受的是**用户发起的单页真实浏览器读取**，不扩大为采集器，不绕过登录/验证，不并发。
- 证据断言：任务日志显示浏览器工具调用 2 次；`fetchText` / 采集器对 swufe 调用 0 次；启动参数无 stealth（测试断言）。

## 5. 抽取与写库

- 输入：截图 1（列表）+ 截图 2（详情/参会单位）；只依据截图与页面标题，不额外抓 URL。
- 输出 JSON：`events[]`、`projects[]`、`evidence`（截图 id + 行/区域）。
- 活动字段：`title`、`startAt`、`endAt`、`venue`、`school=西南财经大学`、`city=成都`、`kind=双选会`；读不到留空。
- 项目字段：`eventRef`、`company`、`title`、`positions`、`requirements`、`applyMode`、`applyUrl`；读不到留空，不猜。
- 联系方式（联系人 / 手机 / 邮箱 / 微信 / 身份证）：丢弃；任务卡标「含联系方式，已跳过」；不入库、不进审计。
- 写入：`source_id='manual'`；`source_url` 记录页面 URL（只记录，不抓）；`notes` 标「浏览器截图读取（非采集器），未走自动抓取」；单位作为 `event_projects` 行；不写 `company.db`。
- 幂等：每次写工具调用带 `idempotencyKey`；同键重试不新增；一次调用 = 一批；任务可多批。
- 审计：`actor_type=model_api`；`source_ref=artifact:<截图>`；old/new 整行；写失败即不落数据（fail closed）。
- 重复：空库首验只 create；重复提交靠幂等键与 `source_key`，不产生重复活动/单位。

## 6. 外部 Agent 复核

- 位置：抽取后、写库前。
- 调用：应用作为 MCP client，调用外部 Agent 的一个可接收 prompt 并返回文本的工具；prompt = 抽取 JSON + 来源元数据 + 「只列问题，不改数据，不读图」。
- 期望输出：问题列表 `{row, field, issue, severity}`；解析失败则存原始文本。
- **建议制**：不自动修改写入集；问题存任务证据；任务卡显示「复核 N 个问题」+ 链接；解析失败显示「已复核」。
- 调用记录：只进助手消息的调用表（`step=review`、backend、耗时、tokens/费用），不进任务记录（#17）。
- 失败：`CONNECT_FAILED` / 超时 / 协议错 → 任务继续，标「外部 Agent 复核不可用」+ code + recovery；写库照常；**Agent 路径记为未通过**，需补一次成功调用才满足验收。
- Agent 不获得本应用写工具；不跨后端回退；不把截图或敏感正文交给 Agent（只给抽取 JSON）。
- 环境：真实 Agent 成功一次（Claude Code；回退 Coze）；确定性测试用本地 MCP stub。

## 7. 审计与撤销

- 每次写工具调用 = 一批；数据 + 审计 + 幂等同事务。
- 任务级撤销：批次新→旧；单批预检；逆操作；冲突 `skip`；单批事务；结果「已撤销 N / 冲突 M / 失败 K」。
- 干净用例：撤销后 `events` / `event_projects` 与验收前快照一致（行数 + 内容 sha256）；审计新增 undo 事件；幂等行保留（7 天 TTL）。
- 冲突用例：写后手工改 1 行 `event_projects.title`；撤销 → 该行 `skip`，其余撤销，任务卡「已撤销 N-1 / 冲突 1」；强制撤销 → 写回 `old_values`，`result=forced`；审计同时有 `skip` 与 `forced`。
- 不做 redo；采集器批次不可撤销（首验无采集器）。

## 8. 界面与状态

- 来源卡：来源校对入口；不改成「已接入」；显示「最近手动读取」+ 原因。
- 对话：任务发起后回对话并打开抽屉；任务卡状态：运行中 / 成功 / 失败 / 复核不可用 / 已撤销；证据链接；批次数。
- [审计与撤销面板原型](https://github.com/Lumichelka/career-agent/issues/23)：按批分组、diff、撤销结果、强制二次确认（不要求输入词）。
- 错误面（#13 §8.3）：视觉 `AUTH_FAILED` / `CONNECT_FAILED` / `REQUEST_TIMEOUT`；Agent `CONNECT_FAILED`；blocked；每条带 recovery。
- 手机端不在本验收通过条件；按 [工作流面板与任务状态原型](https://github.com/Lumichelka/career-agent/issues/18) / [审计与撤销面板原型](https://github.com/Lumichelka/career-agent/issues/23) 另测。

## 9. 成功标准

1. **入口**：来源卡「来源校对」可用；任务回对话并打开抽屉；源卡片仍 disabled，记「最近手动读取」。
2. **边界**：浏览器工具 2 次；`fetchText` / 采集器对 swufe 0 次；无 stealth；无登录/验证绕过；无翻页/批量。
3. **抽取**：清晰可读活动 **100%** 写入；清晰可读参会单位 **≥90%**；单位名逐字正确；**零编造**（每个值能在截图指认，不确定留空）；联系方式 0 条入库/入审计。
4. **写库**：只写 `events` + `event_projects`；`source_id='manual'`；`source_url` 记录；`company.db` 0 写；无重复行。
5. **审计**：数据行与审计事件 1:1；old/new 完整；fail closed；`source_ref` 指向截图证据。
6. **复核**：真实 Agent 成功 1 次；问题/结果存证据；未自动改数据；调用记录在助手消息；失败降级可复现。
7. **撤销**：干净用例前后数据一致；冲突用例 1 skip + 强制写回；结果计数与审计一致。
8. **界面**：任务卡 / 审计面板 / 错误码 / recovery 均正确。
9. **时间与成本**：整任务 ≤ 15 分钟；调用记录有 tokens 与 ≈¥。
10. **证据与签字**：证据包齐全；owner 在证据包 README 写「验收通过 + 日期」。

## 10. 失败标准

任一即失败：

- 出现编造的行或字段；活动漏 1 场；单位覆盖率 < 90%；重复活动/单位。
- 联系方式进入数据库或审计 `new_values`。
- 写入 `company.db`；出现未审计的写入；审计与数据行不 1:1。
- 撤销后数据表与验收前快照不一致；冲突未显示 `skip`；强制撤销未记 `forced`。
- 采集器被调用；`fetchText` 直连 swufe；stealth 参数；绕过登录/验证；翻页/批量。
- 真实 Agent 未成功调用一次；复核自动改了写入集。
- 任务超过 15 分钟；静默换后端；错误码缺 recovery；live 运行出现未处理异常。
