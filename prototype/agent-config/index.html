#24 · 外部 Agent 的配置、连接状态与工具列表在网页端怎么呈现

三个形态只换「放哪、怎么分级」，共用同一套内容：配置表单、连接状态、工具列表、MRTR 开关、空 / 失败状态。顶栏可切形态、切状态（失败码、排队、回收、没有 Agent）、切身份（owner / 成员，成员看不到 stdio）。

A · 设置页配置 + 状态 + 工具都在现有「模型与接口设置」对话框；对话页只留入口和提示
B · 工作流抽屉全部进 #18 的右侧抽屉；设置只留模型，连接编辑在抽屉里的第二层
C · 两处分工设置管配置（CRUD / 凭据 / MRTR），抽屉管运行时（状态 / 工具 / 测试 / 刷新）

双击本文件即可跑；无构建、无请求、状态只在内存里。链接里的参数：?variant=A|B|C&state=modern|failed-auth|…&owner=1|0。
